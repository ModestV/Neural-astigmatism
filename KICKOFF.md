# Стартовый промпт для Claude Code

1. Скопируй `CLAUDE.md`, `docs/` и `.claude/` в корень пустого репозитория.
2. Положи реальные данные в `data/real/` (чертёж + `instances_Train.json`).
3. Запусти Claude Code на Opus (`/model` → Opus 5.5) и вставь текст ниже.

---

Ты главная сессия (Opus) проекта SymSpot. Прочитай `CLAUDE.md` и `docs/PLAN.md` целиком.

Цель: довести проект до готового MVP по `docs/PLAN.md`, раздел 7 «Определение готовности».

Как работать:
- Выполняй фазы 0–7 по порядку, каждая заканчивается гейтом из плана.
- Фазу 0 и алгоритмическое ядро фазы 3 (а также verify/mask растра в фазе 5) пиши сам.
- Остальные задачи делегируй сабагентам `sonnet-implementer`, `sonnet-tester`, `sonnet-viz`
  по шаблону брифа из раздела 0. Независимые задачи запускай параллельно (до 3) с
  `isolation: "worktree"`.
- После каждого агента: прочитай дифф, запусти `uv run pytest -q` и `uv run ruff check .`,
  смержи или верни замечания тому же агенту через SendMessage.
- Веди задачи в списке задач: одна задача на каждый пункт T1–T6 и каждый шаг ядра.
- После каждого гейта — коммит и короткая запись в `docs/PROGRESS.md`
  (что готово, метрики, открытые вопросы).
- Если метрика фазы не достигнута, разберись в причинах сам (визуализируй ошибки через
  рендер), прежде чем двигаться дальше. Порог в конфиге менять можно, критерий в плане нельзя.
- Ничего не спрашивай у меня, кроме решений, которые нельзя откатить. Неясности решай сам
  и записывай решение в `docs/PROGRESS.md`.

Начни с фазы 0.
