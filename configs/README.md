# configs

Все эксперименты описываются YAML-файлами, а не кодом. Чтобы добавить свою модель или адаптер,
скопируйте `_template.yaml` из нужной папки и заполните его. Имя файла должно совпадать с полем `name`.

| Папка | Что описывает |
|---|---|
| `base_models/` | базовая LLM: id на HuggingFace, слои для LoRA, владелец |
| `adapters/` | адаптер: базовая модель + датасет + метод обучения + защита от забывания |
| `training/` | гиперпараметры метода: lora, qlora, dora |
| `forgetting/` | защита от забывания: none, replay, ewc |
| `eval/` | набор бенчмарков и метрик |

Файлы, начинающиеся с `_`, — шаблоны, в эксперименты не попадают.
Поле `owner` — GitHub-ник участника, который отвечает за конфиг.
