# app

Streamlit-демо SymSpot: поиск обозначений на чертеже по эталонам с того же чертежа.

## Запуск

    uv sync
    uv run streamlit run app/demo.py

Сайдбар: загрузка чертежа (pdf, svg, png, jpg) и файла эталонов (COCO или простой JSON),
номер страницы PDF, пороги (accept_score, cover_tol, scale_min, scale_max, allow_mirror),
кнопка «Пример» (генерирует small-синтетику по заданному seed) и кнопка «Найти».

Основная область: оверлей (PNG или интерактивный HTML-отчет с zoom/pan), таблица экземпляров
с фильтром по классу, отдельный список ambiguous, сводка по классам, тайминги, метрики
P/R/F1 (если в файле эталонов есть разметка экземпляров: GT синтетики или COCO с категорией
`object`), кнопки скачивания overlay.svg, overlay.pdf, result.json, report.html.

Результат прогона хранится в `st.session_state`, повторная отрисовка поиск не перезапускает.
Загрузки сохраняются во временный каталог под исходными именами.

## Тесты

    uv run pytest tests/app -q
