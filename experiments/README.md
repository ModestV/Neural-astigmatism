# Личные эксперименты

Каждый участник работает в своей папке `experiments/<github-username>/`:
черновые ноутбуки, заметки, результаты прогонов.

Правила:
- код, который пригодился всем, переносите в `src/peft_lab/` через PR;
- веса и большие файлы сюда не кладите: они идут в `outputs/` (не в git) или на HuggingFace Hub;
- общие исследовательские ноутбуки кладите в `notebooks/`.
