# Личные эксперименты

У каждого участника своя папка: `experiments/<ник-на-github>/`. Туда идут черновики, пробные
скрипты и ноутбуки, их можно менять без согласования с командой.

Чужие папки не трогаем. Код, который пригодился, переносим в `backend/app/detection/`
(алгоритмы) или `scripts/` (утилиты) и покрываем тестами.

Большие файлы (чертежи, веса моделей, результаты) в git не кладём.
