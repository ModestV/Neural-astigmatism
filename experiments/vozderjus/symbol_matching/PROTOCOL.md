# Протокол сравнения на предоставленных PDF и COCO

Зафиксирован до получения итоговых результатов. Это исследование трёх конкретных baseline-реализаций,
а не утверждение об оптимальной достижимой точности семейств алгоритмов.

## Данные и задача

- Первичная разметка пользователя COCO используется как эталон. Полнота принимается по назначению,
  указанному пользователем; новая ручная разметка и отметки редактора не требуются.
- 9 размеченных страниц, 719 объектов на планах, 135 образцов из легенд.
- Все legend_item используются как запросы, включая обозначения без экземпляров на плане.
- legend_id относится только к своему PDF/странице, не объединяет одинаковые номера разных чертежей.
- 03_washoe_house.pdf не содержит аннотаций и не используется как отрицательная страница.
- Области легенды исключаются из поиска/оценки по попаданию центра рамки. Образцы берутся только
  из легенды, искомые позиции из разметки не используются для настройки поиска.

## Разделение до настройки порогов

Calibration: 01_riga_lighting.pdf, 02_renee_house.pdf, 06_camden_lighting.pdf.
Test: 04_lakeview.pdf, 05_missouri_power.pdf, 07_argentina_i2esq.pdf,
10_onliner_apartment.pdf, 8_petrovich_voskova.pdf, 9_tdm_two_room.pdf.
Разделение по PDF, а не по соседним фрагментам одного листа.

## Общая подготовка и ограничения

- Растеризация одинаковая: 150 DPI, grayscale; рендер и запись файлов не включаются в время поиска.
- Масштабы: 0.5, 0.75, 1, 1.25, 1.5, 2. Углы: 0, 90, 180, 270 градусов.
- Template Matching: TM_CCORR_NORMED на инвертированной яркости, дискретный перебор.
- ORB: edgeThreshold=7, patchSize=15; SIFT: стандартный детектор. До 20 000 ключевых точек
  страницы/образца, признаки страницы переиспользуются между запросами.
- Feature matching: Hamming для ORB, L2 для SIFT, ratio test 0.75, минимум 4 различных inliers,
  RANSAC преобразования подобия, reprojection threshold 3 px, максимум 5000 итераций на гипотезу.
- У признаковых методов угол допускает отклонение 10°, масштаб 15% от одного заданного значения.
  Это не полная эквивалентность дискретному перебору Template Matching.
- Минимальный пространственный разброс inliers: 1% площади образца. Последовательный RANSAC
  выделяет несколько экземпляров. NMS IoU 0.3. До 200 кандидатов на запрос.
- Слишком маленькие образцы, недостаток ключевых точек и срабатывание лимитов сохраняются
  в диагностике и не приводят к исключению соответствующих эталонных объектов из знаменателя Recall.
- Один поток OpenCV, seed=42. Зеркальные и произвольные углы не проверяются.

## Настройка

Только на calibration выбирается порог по максимальному micro-F1; при равенстве — precision,
затем более строгий порог. Для Template Matching проверяются 0.75/0.8/0.85/0.9/0.95,
для доли inliers ORB/SIFT — 0.35/0.5/0.65/0.8/0.95. Кандидаты сохраняются на нижнем пороге;
более строгие оценки получаются фильтрацией тех же кандидатов. Выбранные пороги записываются
до вычисления test. Другие параметры на test не подбираются.

## Оценка

Единые объектные Precision, Recall и F1: совпадение класса и IoU >= 0.5, один эталон на одну детекцию.
Предсказания идут по убыванию score внутри метода. Дубликат после первого совпадения — FP.
Основной результат — micro-метрики на шести test-листах. Calibration и все 9 листов приводятся отдельно.
Отчёт содержит TP/FP/FN, результаты каждого PDF и причины неудач.

Время: один измеренный проход поиска всех образцов страницы, включая однократное выделение
признаков страницы. Порядок алгоритмов циклически меняется между страницами. Отдельно указываются
суммарное время, медиана по различным листам и время на запрос. Это описательный замер,
не статистическая оценка производительности при повторных запусках.

Разметка содержит осевые bbox; один атрибут rotation=1° сохранён в исходных данных, но не меняет
формулу IoU. Небольшой набор и возможные ошибки эталона ограничивают обобщение выводов.

Техническое уточнение до итогового test: точный жадный выбор пиков Template Matching
ускорен очередью максимумов плиток. Порядок максимумов и правило подавления сохраняются;
эквивалентность исходному полному сканированию проверяется на случайных картах и плато.
Промежуточный медленный прогон прерван и не используется в итоговом сравнении времени.
