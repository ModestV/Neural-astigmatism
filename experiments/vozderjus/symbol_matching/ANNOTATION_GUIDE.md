# Редактор разметки ИУО

Локальный инструмент для выбора образцов и редактирования всех экземпляров на странице PDF.
Новые библиотеки не нужны: Python, Pydantic, PyMuPDF и OpenCV уже входят в окружение исследования.
Редактор работает в браузере без внешнего сервиса, доступен только на этом компьютере.

## Запуск

На macOS дважды нажмите `Разметка.command` в Finder внутри папки исследования.
Или выполните из корня репозитория:

```sh
backend/.venv/bin/python experiments/vozderjus/symbol_matching/annotate.py
```

Сервер выберет свободный порт и откроет браузер. Пока работает редактор, окно терминала нужно оставить
открытым. Для остановки — Ctrl+C. При новом запуске адрес/токен меняется, данные остаются на диске.
Можно использовать `--no-browser`, чтобы скопировать выданную ссылку вручную.

Пути по умолчанию определяются относительно скрипта. Доступны `--drawings-dir`, `--workspace`,
`--cache-dir`, `--export-dir`, `--port`. Явные относительные пути зависят от текущей папки терминала.

## Уже добавленная разметка

При первом запуске редактор ищет COCO JSON во вложенных папках `drawings/` и импортирует их в новую
рабочую копию `annotations/workspace.json`. Повторный запуск открывает сохранённую рабочую копию,
а не повторяет импорт и не заменяет внесённые изменения. Чтобы отдельно импортировать обновлённый
набор, укажите новое имя через `--workspace annotations/another_workspace.json`.

Проверенный набор пользователя: 3 экспорта, 10 изображений, 854 рамки, 135 обозначений по легендам.
На одной странице нет рамок, она остаётся непроверенной. Один атрибут `rotation` равен 1°;
он сохранён в `source`, но редактор использует осевые bbox из COCO, а не повёрнутые прямоугольники.
Исходные PDF, изображения и JSON не изменяются.

Импорт поддерживает категории `object` и `legend_item`, связь берётся из `attributes.legend_id`.
Номера scoped по исходному чертежу и странице: ИУО 1 на разных листах не объединяются автоматически.
Категории с другими именами и `iscrowd` требуют явного правила преобразования и вызывают ошибку.
Имена вида `04_lakeview[1]000000000.jpeg-1.jpg` сопоставляются с соответствующей страницей PDF.
Пиксельные bbox масштабируются к видимой странице с учётом её размеров. Несовпадение пропорций
COCO и PDF более 0.5% блокирует импорт; обрезанные/растянутые картинки требуют отдельного преобразования.
Соотношение сторон не доказывает совпадение содержимого: наложение рамок стоит просмотреть вручную.

## Работа в редакторе

1. Выберите PDF слева. Галочка у класса выбирает его для исследования; нажатие на имя делает класс
   текущим для рисования и списка экземпляров.
2. Нажмите экземпляр в списке справа: редактор приблизит его. Колесо меняет масштаб, пробел с
   перетаскиванием или режим «Рука» перемещает страницу. «Весь лист» возвращает общий вид.
3. «Рамка» (`R`) — нарисовать новый экземпляр текущего класса.
   «Выбор» (`V`) — выбрать рамку, передвинуть её или изменить размер за углы.
   `H` — рука. Кнопки и Ctrl/Cmd+Z / Ctrl/Cmd+Shift+Z отменяют/повторяют действия.
4. Справа можно изменить класс, координаты и флаг «Элемент легенды», удалить рамку.
   Числовые координаты задаются в пунктах отображаемой PDF-страницы, не в пикселях.
   Delete удаляет выбранную рамку; Esc отменяет текущее перетаскивание/выделение.
5. У чистого изображения ИУО включите «Использовать как образец поиска». Этот класс автоматически
   включится в исследование. Можно выбрать несколько образцов одного класса. Рамка в легенде
   не становится образцом автоматически: она может захватывать подпись/таблицу и требовать правки.
6. Просмотрите все экземпляры выбранного класса и только затем включите
   «Все экземпляры этого класса на листе проверены». Правки геометрии, класса или флага легенды
   снимают отметку проверки для затронутых классов. Переименование и выбор образца её не снимают.
7. Нажмите «Экспорт текущего листа». Для каждого выбранного класса нужен хотя бы один образец.

Тонкие серые рамки — другие классы, зелёные — текущий класс, жёлтые — легенда,
фиолетовые — выбранные образцы, синие — выделенная рамка. В выпадающем списке классов показаны
обозначения текущего листа и пользовательские классы, чтобы не смешивать номера разных чертежей.

Изменения сохраняются автоматически после завершения действия. Кнопка «Сохранить» и Ctrl/Cmd+S
сохраняют сразу. Надпись «Сохранено на компьютере» подтверждает запись. «Скачать копию» позволяет
отдельно получить текущий JSON, в том числе при конфликте другой вкладки.

## Экспорт и метрики

Экспорт создаёт новый JSON в `annotations/exports/`, не заменяет рабочую копию и исходный COCO.
Выдаются образцы выбранных классов, целевая страница, эталонные bbox и исключаемые области легенды.
Отдельный файл для текущего листа предотвращает смешение разных словарей легенд.

Если все выбранные классы проверены, `ground_truth` содержит эталонную разметку.
Если хотя бы один выбранный класс не проверен, `ground_truth` остаётся `null` с предупреждением:
запуск алгоритмов возможен, но метрики не вычисляются. Пустой список не возникает автоматически
из-за отсутствия аннотаций в импорте.

Конфигурация совместима с существующим запуском:

```sh
backend/.venv/bin/python experiments/vozderjus/symbol_matching/run_benchmark.py run \
  --config 'ПУТЬ_ИЗ_ОКНА_ЭКСПОРТА' --algorithms template orb sift --dpi 150
```

Плейсхолдер пути замените на фактически выданное имя файла. Модельный score не используется для
автоматического подтверждения разметки; результаты алгоритма не превращаются в эталон сами.
Рамки легенды и область исходного образца исключаются из оценки по правилам исследования.

## Сохранность данных

- `workspace.json` хранится отдельно от оригиналов, запись атомарная.
- Последние 20 резервных копий — `annotations/.annotation_backups/`; они не входят в Git.
- Конфликт ревизии другой вкладки останавливает сохранение вместо молчаливой перезаписи.
- Смена SHA256, размера или поворота PDF блокирует сохранение/экспорт до проверки привязки.
- Загруженная рабочая копия не дополняется новыми PDF автоматически.
- Не запускайте несколько серверов редактора одновременно с одним и тем же файлом workspace.

Для восстановления: остановите редактор, сохраните текущий workspace отдельно, скопируйте нужную
резервную копию на его место и запустите редактор снова. Также можно открыть копию отдельным
параметром `--workspace` и продолжить работу с ней.

## Проверки

```sh
cd backend
.venv/bin/python -m pytest tests/test_symbol_annotation.py
```

Проверяются масштаб и поворот, разделение legend_id разных PDF, отказ от неоднозначного импорта,
проверенность разметки, ревизии, резервные копии, привязка к PDF и локальные HTTP-сохранение/экспорт.
Одна проверка открывает только локальный 127.0.0.1; внешний интернет не используется.
