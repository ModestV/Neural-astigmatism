# Сравнение алгоритмов поиска условных обозначений

Исследование vozderjus: ORB+RANSAC, SIFT+RANSAC и Template Matching.

## Структура

- `algorithms/` — будущие реализации алгоритмов.
- `drawings/` — локальные исходные векторные PDF, содержимое исключено из Git.
- `annotations/` — образцы и эталонная разметка; небольшие JSON можно хранить в Git.
- `cache/` — воспроизводимые растровые представления страниц, исключены из Git.
- `results/` — локальные результаты запусков, исключены из Git.

Предусмотрен будущий единый скрипт `run_benchmark.py`. Код пока не создан.
PDF нужно разместить в `drawings/`; пути в разметке следует задавать относительно этой папки,
без абсолютных путей к компьютеру участника.

## План организации запуска

По умолчанию пути определяются относительно расположения скрипта, независимо от текущего каталога.
Планируемые параметры: `--drawings-dir`, `--annotations-dir`, `--output-dir`, `--dpi`, `--algorithms`.
Кэш и каталог отдельного запуска создаются автоматически. Для воспроизводимости вместе с результатами
сохраняются параметры, версии библиотек и контрольные суммы входных PDF.
Растеризация всех алгоритмов должна использовать одинаковые настройки.

Большие файлы передаются отдельно; источник и способ получения описываются в `drawings/README.md`.
Небольшие итоговые таблицы и графики для команды можно отдельно публиковать в `report/`.
