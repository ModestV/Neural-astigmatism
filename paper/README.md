# Научно-техническая статья

Черновик структуры:

1. Введение и актуальность
2. Обзор PEFT-методов (LoRA, QLoRA, DoRA) — из `docs/theory/`
3. Методология: пайплайн, датасеты, защита от забывания
4. Эксперименты: качество, деградация базовых знаний, стоимость
5. Переносимость и комбинирование адаптеров
6. Выводы

Графики кладите в `figures/`; скрипт, который строит каждый график, должен лежать в репозитории.
