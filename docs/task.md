# Постановка задачи

Текст кейса «Поиск на чертежах условных обозначений из заданного набора».

## Описание проекта

Современные двумерные чертежи разнообразных конструкций являются сложными многомерными и многослойными
текстами, насыщенными информацией и составленными на богатом визуальном языке, который развивается более
500 лет. В отличие от обычных текстов чертежи не одномерные и не линейны, при их чтении важны пространственные
соотношения между их элементами. В отличие от фотографических или художественных изображений, чертежи могут
содержать большое количество разнородной информации в элементе растрового изображения, их требуется
обрабатывать в различных масштабах. Современные модели для работы с визуально-текстовой информацией плохо
справляются с задачей обнаружения условных обозначений на чертежах на достаточно достоверном для практических
задач уровне. Требуется их доработка, и/или создание специальных алгоритмических обвязок (harness), и/или
создание специализированных моделей.

Проект предполагает у участников наличие и интерес к развитию следующих компетенций: умение применять на
практике базовые прикладные аспекты теории вероятностей, навыки работы с классическими методами обнаружения
объектов на изображениях (например, RANSAC), знакомство с архитектурами современных моделей для компьютерного
зрения, знакомство с архитектурой современных больших языково-визуальных моделей, навыки программирования на
языках Python и/или Julia.

## Цель

Разработка моделей и алгоритмов для точной детекции расположения определённых (заданных набором
геометрических шаблонов) графических условных обозначений на чертежах, представленных в векторном формате
(DWG, или PDF, или SVG).

## Результат (продукт)

Задача может быть решена различными способами, но можно ожидать, что наиболее эффективным окажется комбинация
детерминированного алгоритма и оракула/эвристики на основе модели, построенной методами машинного обучения.
Результатом проекта должны быть:

1. Формальные математические описания алгоритма и модели. Если обучение ML-модели требует формирования
   обучающего набора данных, то этот набор данных должен быть включён в результат.
2. Прототипная реализация алгоритма на одном из языков программирования Python или Julia.

## Критерий оценки

Результат будет принят при предоставлении следующих артефактов:

1. Математическое описание алгоритма и ML-модели, обоснование выбранных подходов с обзором современной
   литературы.
2. Прототипная реализация алгоритма на одном из языков программирования Python или Julia.
3. Отчёт с анализом качества работы алгоритма и предложениями по его улучшению.
