### Решения
- Дуга: точка(t) = c + r(cos t, sin t) в координатах чертежа (Y вниз), t0 < t1.
- Similarity: p' = s R(θ) M p + t, M = diag(1, -1) при mirror.
- У кусков два родителя: `parent_id` (исходный подпуть файла, для раскраски) и `stroke_id`
  (примитив до планаризации). Правило «родитель в рамке >= 0.8» при извлечении эталона
  считается по штриху (`stroke_id`): подпуть PDF может объединять стену и символ.
- ParentPath = связный подпуть (разбиение по moveto), а не целый объект файла.
- Ридеры отдают только родителей и TextPrim, Segment/Arc строит нормализация.
- Пороги нормализации (`flatten_tol`, `arc_fit_tol`, `merge_gap`, `snap_tol`) заданы в долях
  опорного размера символа (медиана диагоналей рамок эталонов).
- Ключи пар: якоря двух примитивов задают подобие однозначно (две точки), поэтому вариант
  «2 направления отрезка» не нужен; отражение = отдельный проход с отраженным эталоном.
- Экземпляр, совпадающий с самим эталоном (легенда), помечается `is_query` и исключается из
  метрик.

## Фаза 3. Ядро (готово)

- 3.1-3.8 реализованы, тесты по спецификации (sonnet-tester, `tests/core_algo`) зеленые.
- Отклонения от буквы плана (критерии фаз не менялись):
  - ключи пар считаются по штрихам (куски, собранные по `stroke_id`), а не по кускам:
    ключи не зависят от того, как планаризация разрезала линии символа;
  - соревнование запускается по перекрытию «пересечение / меньшая площадь» > 0.5, а не по
    IoU: вложенные символы (duplex в рамке GFCI) дают IoU ~0.4;
  - сходство эталонов в 3.5 = направленное покрытие с учетом касательных
    (`similar_cover` = 0.85) вместо среднего chamfer: chamfer признавал похожими квадрат и ⊘;
  - гипотезы от совпадающего текста (source="text") с широким стартовым радиусом ICP;
    ICP точка-прямая, затем точка-точка; для эталонов на одной прямой ICP уточняет только
    сдвиг;
  - лишняя тушь не учитывает штрихи, проходящие насквозь (стена через мелкий символ);
  - `resolve` упорядочивает классы по абсолютной длине линий и текста.
- Порог `min_distinct_pairs` ограничивается числом пар эталона (⊘ = 2 штриха = 1 пара).

## Фаза 4. Векторный пайплайн (готово)

- `pipeline.run`, CLI `symspot run/eval/synth`, e2e-тесты.

  F1 = 0.999.
- Оставшиеся пропуски: один `bell` (зеркальный, со стеной), один `switch_s3` в PDF.

## Фаза 5. Растр (готово)

- preprocess (Sauvola, скелет, направления) и chamfer-поиск (sonnet); проверка, маски,
  конвейер (Opus). Схема chamfer из плана (свертка листа на каждую позу) заменена плотным
  проходом на уменьшенном растре + перебор поз в центрах: иначе не укладывается в бюджет.
- `raster_accept_score` = 0.9 (TP: покрытие >= 0.97 в 10-м процентиле, FP: медиана 0.90);
  рамка растрового экземпляра по трансформированным сэмплам; `similar_cover` = 0.6 (пары
  «круг + разный текст» покрывают друг друга на ~75 %).
- Метрики (5 small): чистый PNG F1 = 0.872, «грязный» F1 = 0.838 (цели 0.85 и 0.7).

## Организация работы

- Isolation `worktree` у Agent создает worktree от origin/main (без symspot). Решение:
  worktree создаются вручную от HEAD `claude_mvp`, путь указывается в брифе.
- Сабагенты делят scratchpad: свои отладочные скрипты главная сессия держит в `scratchpad/opus/`.
- cairosvg на macOS не находит libcairo из Homebrew без подсказки: загрузка через
  `symspot/render/_cairo.py` (и аналог в `synth/export.py`).
