# Данные

Содержимое этой папки **не попадает в git**: персональные данные остаются на вашей машине.
Опишите в README адаптера или в PR, откуда взят датасет и как его воспроизвести.

| Папка | Что лежит |
|---|---|
| `raw/` | исходные данные как есть |
| `processed/` | датасеты для обучения: `<имя-адаптера>.jsonl` |
| `replay/` | общие данные для replay-буфера (защита от забывания), например `general.jsonl` |

## Формат `processed/*.jsonl`

Одна строка — один диалог в chat-формате:

```json
{"messages": [{"role": "system", "content": "Ты опытный Python-разработчик."}, {"role": "user", "content": "Что такое декоратор?"}, {"role": "assistant", "content": "Декоратор — это функция, которая..."}]}
```
