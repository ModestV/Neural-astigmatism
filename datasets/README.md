# Наборы данных

Если для ML-модели понадобится обучающий набор, он должен войти в результат проекта. Здесь лежат
сами наборы (если небольшие) или их описание и ссылка на внешнее хранилище (если большие).

Небольшие тестовые чертежи с эталонной разметкой лежат в [samples/](../samples/).

## Правила

- Для каждого набора — своя папка с `README.md`: откуда данные, лицензия, сколько листов
  и обозначений, формат разметки, как пересоздать.
- Файлы больше нескольких мегабайт в git не кладём. Набор публикуем, например, на HuggingFace Hub,
  Яндекс Диске или Google Drive, а сюда пишем ссылку и скрипт загрузки.
- Чужие чертежи берём только с лицензией, разрешающей такое использование.

## Формат разметки

Скрипт метрик (`scripts/evaluate.py`) читает два формата:

- **Наш JSON** — как [samples/ground_truth.json](../samples/ground_truth.json): для каждого
  файла и листа список экземпляров с полями `symbol`, `bbox` (`[x, y, w, h]` в единицах страницы,
  ось Y вниз), `angle` и `legend` (экземпляр из таблицы условных обозначений). Основной формат для
  векторных PDF: координаты в единицах листа, есть листы, его легко дополнить списком штрихов.
- **COCO** — выгрузка из CVAT и других инструментов разметки. Картинка — чертёж из одного листа,
  координаты в пикселях, категория `legend_item` — таблица обозначений.

Новый формат подключается загрузчиком в `backend/app/evaluation/dataset.py`.
