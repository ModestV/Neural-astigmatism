# Размеченный набор чертежей (labeled-dataset)

Чертежи с ручной разметкой условных обозначений и таблиц условных обозначений (легенд).
Разметка сделана в CVAT и выгружена в формате COCO 1.0. Набор нужен для обучения и проверки
алгоритма поиска обозначений (см. [docs/task.md](../../docs/task.md)).

## Где лежат данные

| Что | Где |
|---|---|
| Разметка COCO (маленькие JSON-файлы) | в git: [annotations/](annotations/) |
| Сами чертежи и картинки (десятки МБ) | Google Drive: <https://drive.google.com/drive/folders/19NXyLY5hIcQWHJD-pqAttZYS3-de1yua> |

Чертежи в git не кладём: по правилам проекта большие файлы публикуются отдельно (см. [datasets/README.md](../README.md)).

(эта папка в `.gitignore`).

## Что размечено

Два класса:

- `object` — экземпляр условного обозначения на плане;
- `legend_item` — образец обозначения в таблице условных обозначений (легенде).

Рамка `object` связана с соответствующей рамкой `legend_item` через атрибут `legend_id`:
у них одинаковое значение `legend_id` (в пределах одного листа). Так можно узнать, какому пункту
легенды соответствует найденный объект.

Дополнительные атрибуты рамок: `rotation` (поворот, градусы), `occluded` (частично закрыт).
В `svg_supertest.json` есть ещё `status`, `confidence`, `meaning`.

## Формат и особенности

- **Номера классов в файлах разные.** В `pdf_part1.json` и `pdf_part2.json` `object = 1`, а в
  `pdf_part3.json` и `svg_supertest.json` — `object = 2` (у `legend_item` наоборот).
  При объединении файлов сопоставляйте классы **по имени** (`name`), а не по `category_id`.
- В `pdf_part2.json` и `pdf_part3.json` в списке категорий есть пустой класс `temporary`:
  рамок с ним нет, его можно игнорировать.
- **Координаты в пикселях картинки, а не в единицах страницы.** Рамка COCO — `[x, y, w, h]` в пикселях
  растровой картинки листа (см. размеры в таблицах), начало слева сверху, ось Y вниз. Проектный формат
  [samples/ground_truth.json](../../samples/ground_truth.json) использует единицы страницы
  (PDF/SVG), поэтому при сравнении нужен пересчёт по масштабу «картинка → страница».
  Конвертера пока нет.
- Имена листов в `file_name` — это имена картинок, например `02_renee_house000000000.jpeg-1.jpg`.
  Соответствие исходным PDF/SVG — по началу имени (`02_renee_house` → `02_renee_house.pdf`).

## Источник и лицензия

Источник чертежей **не установлен**: их подобрали с помощью ИИ-ассистента, адреса исходных файлов
не сохранены. Лицензия **не проверена**. Правила проекта разрешают использовать чужие чертежи только
с лицензией, допускающей такое использование, поэтому до выяснения источника набор считается
**внутренним учебным** и не должен публиковаться вне команды.

## Как делали разметку

Разметка выполнена вручную в CVAT: рамки двух классов и атрибут `legend_id`, связывающий объект
с пунктом легенды. Экспорт — «COCO 1.0».
