# Общие ноутбуки

Jupyter-ноутбуки, которые нужны всей команде: разбор данных, сравнение алгоритмов, графики для отчёта.
Личные черновики — в `experiments/<ник>/`.

Перед коммитом очищайте вывод ячеек с большими картинками, чтобы репозиторий не разрастался
(`Kernel → Restart & Clear Output` или `jupyter nbconvert --clear-output`).
