# Поиск на чертежах условных обозначений из заданного набора

Командный проект: модели и алгоритмы для точной детекции графических условных обозначений, заданных
набором геометрических шаблонов, на чертежах в векторном формате (DWG, PDF, SVG).
Полная постановка — [docs/task.md](docs/task.md).

> **Статус:** создана структура репозитория. Код сервиса добавляется следующим шагом.

## Что сдаём

| Артефакт | Где |
|---|---|
| Обзор литературы и обоснование подхода | [docs/literature/](docs/literature/) |
| Математическое описание алгоритма и ML-модели | [docs/math/](docs/math/) |
| Прототип алгоритма на Python или Julia | `backend/app/detection/` |
| Обучающий набор данных (если нужна ML-модель) | [datasets/](datasets/) |
| Отчёт о качестве и предложения по улучшению | [report/](report/) |

## Структура

```
docs/              постановка задачи, обзор литературы, математика, архитектура
backend/           веб-сервис на FastAPI; app/detection/ — алгоритмы поиска
frontend/          интерфейс на React + TypeScript
samples/           тестовые чертежи и эталонная разметка
datasets/          обучающие наборы данных
experiments/       личные черновики: experiments/<ник-на-github>/
notebooks/         общие ноутбуки
report/            отчёт о качестве, figures/ — графики
scripts/           утилиты
```

В каждой папке есть `README.md`: что в ней лежит и как с ней работать.
