# Фронтенд Symbol Search

React + TypeScript + Vite. Запуск, структура и устройство проекта описаны в [README в корне](../README.md).

```sh
npm install
npm run dev      # http://localhost:5173, /api проксируется на http://127.0.0.1:8000
npm run lint     # oxlint
npm run build    # сборка в dist/ — её раздаёт бэкенд
```
